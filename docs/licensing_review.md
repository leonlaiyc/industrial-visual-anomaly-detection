from its dataset licence. The snapshot does not vendor upstream framework implementation files.

The network is torchvision `Wide_ResNet50_2_Weights.IMAGENET1K_V1`, downloaded at runtime and not bundled.

[official pretrained-model guidance](https://docs.pytorch.org/vision/stable/models.html) separately requires
users to determine model-use rights from training-data terms. [ImageNet terms](https://image-net.org/download.php)
limit database access to non-commercial research/education. Those database terms do not, by themselves,
settle every pretrained-weight right. Commercial model use remains unresolved and requires review.

## Ultralytics / YOLOv8s / YOLO11s

Actual training and COCO pretrained-weight hashes are recorded in `exploratory/yolo_pcb4/audit/training_record.json`.
The exploratory scripts import `ultralytics`; it is not a core IVAD dependency. The public candidate includes
those IVAD-authored scripts, configurations, scores and evidence, but no installed Ultralytics source,
pretrained/trained weights, dataset, executable service or inference backend.

[Upstream LICENSE](https://github.com/ultralytics/ultralytics/blob/main/LICENSE) is AGPL-3.0. Its distribution
provisions govern covered works and corresponding source; §13 addresses remote interaction with modified
programs. The static case study does not execute a YOLO service. However, absence of weights or vendored code
does not automatically establish that importing training scripts are outside a larger covered work.
[Ultralytics' current guidance](https://www.ultralytics.com/license) states that its code and trained models
require AGPL compliance for the full derivative project or an Enterprise licence. Its interpretation includes
internal/R&D and proprietary uses. This is the vendor's stated position, not an independent legal conclusion.

**Open gate:** Leon must resolve the licence/scope of the exploratory scripts and any larger combined work
before public source distribution, and obtain guidance for proprietary/commercial deployment. An MIT-only
label for the whole candidate is not established. No weights may be published without separate review and
authorization. A static results/evidence publication also needs a scope review; do not infer that all outputs
of AGPL tools necessarily carry AGPL, or that all outputs are automatically exempt.
